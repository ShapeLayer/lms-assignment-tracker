# 과제 달력

LMS 시스템에 등록된 과제를 브라우저에 저장하고 마감 전에 알리는 Chrome 확장 프로그램입니다.

## Getting Started

이 확장 프로그램을 소속 학교의 LMS 시스템에 사용하려면, 새 LMS Adaptor를 추가하여야 합니다. 자세한 내용은 [LMS Adaptor 개발 가이드](./docs/adaptor.md)를 참고하세요.

## Developing

1. Node.js와 npm을 설치하고 프로젝트 폴더에서 `npm ci`를 실행합니다.
2. `npm run build`를 실행해 `dist/` 폴더를 생성합니다.
3. Chrome에서 `chrome://extensions`를 열고 개발자 모드를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 생성된 `dist/` 폴더를 선택합니다.
5. `https://sel.jnu.ac.kr/`에 로그인합니다. 확장 프로그램을 고정하면 팝업을 쉽게 열 수 있습니다.
6. 팝업의 ↗ 버튼에서 전용 대시보드를 열 수 있습니다. 캘린더의 날짜를 선택하면 해당 날짜의 과제를 볼 수 있습니다.

## 동기화가 되지 않을 때

Chrome 116 이상에서 확장 프로그램을 로드하고, 확장 프로그램을 설치한 **같은 Chrome 프로필**의 `https://sel.jnu.ac.kr/`에서 로그인 상태를 확인합니다. 확장 프로그램 관리 화면의 사이트 액세스에서 LMS 접근이 허용되어 있는지도 확인하세요. Chrome의 서드 파티 쿠키 차단이나 관련 예외 설정에 따라 확장 프로그램의 요청에 LMS 세션이 전달되지 않을 수 있습니다.

확장 프로그램의 설정에서 동기화 오류와 마지막 동기화 시각을 확인한 뒤 다시 시도하세요. `LMS에 연결하지 못했습니다`는 네트워크·접근 권한 문제뿐 아니라 로그인 페이지로 이동하는 리디렉션이 보안 정책에 따라 차단된 경우에도 표시될 수 있습니다. LMS 탭에서 로그인한 다음 재시도해도 해결되지 않으면 브라우저 버전과 표시된 오류를 확인해 주세요.
